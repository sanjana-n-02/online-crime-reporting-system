# Online Crime Reporting System

## Project Overview

The Online Crime Reporting System is a web-based application developed to make crime reporting easier and more accessible. It allows users to submit crime reports online and provides officers with facilities to manage and monitor reported cases.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Main Modules

- User Registration and Login
- Crime Reporting
- Officer Login
- Case Status Tracking
- Contact Information

## Software Requirements

- Visual Studio Code
- XAMPP Server
- MySQL Database
- Web Browser

## How to Run the Project

1. Download or clone this repository.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Import the project database into phpMyAdmin.
5. Configure the database connection files.
6. Open the project in your browser using `http://localhost/your-project-folder/`.
